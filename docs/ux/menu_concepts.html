1 / Lead with the shared gameA short premise and primitive-based facility illustration replace progress statistics as the first impression.

2 / Keep the common path shallowPlay remains primary. Cosmetics, Settings, and explicit Quit retain direct access.

3 / Separate role from rulesBoth roles explain their verbs. Selected state uses a label and border, alongside colour.

4 / Give secondary choices a homeLAN and advanced setup remain visible; the older race has a secondary explicit route.

5 / Confirm what will happenRoster and perspective change with selection. Spectate names a bot-controlled viewpoint and disables human role selection.

Implementation boundaryUse existing semantic Bevy widgets and shared theme/style treatment. This HTML explores hierarchy and layout only. Production labels retain ASCII unless the shipped font changes.

Artwork is decorative, code-drawn geometry. No hidden facility, actual team knowledge, or production gameplay is represented. Layout scales for this review; acceptance is at 1280 × 800.
